## Reporting a Vulnerability

We take the security of our applications, infrastructure, and user data seriously. If you believe you have found a security vulnerability, please report it responsibly by following the instructions below.

### How to Report

**Please DO NOT report security vulnerabilities via public GitHub issues, discussions, or social media.**

Instead, report vulnerabilities through one of the following channels:
- **Private Vulnerability Reporting:** Open a draft security advisory via GitHub (*Security* tab > *Advisories* > *Report a vulnerability*).
- **Security Contact Email:** Send an email to `hyumin.dev@gmail.com` with the subject `[SECURITY] Gym Up Vulnerability Report`.

### What to Include in Your Report

To help us triage and resolve the issue efficiently, please provide:
- A clear description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions, Proof of Concept (PoC) scripts, or sample payloads.
- The affected component (e.g., API endpoint, mobile client version, authentication flow).

### Response SLA & Process

- **Initial Acknowledgment:** You will receive a response within **48 to 72 business hours** confirming receipt of your report.
- **Triage & Assessment:** If the vulnerability is confirmed, we will provide an estimated timeline for a patch.
- **Disclosure:** We follow coordinated vulnerability disclosure. We kindly request that you do not disclose any details publicly until a fix has been deployed and released to production.
